# Changelog

## 0.2.0 - unreleased

- Added HTTP and stdio transports with 13 default core tools, 41 public full tools and 42 owner full tools.
- Stdio serves catalog and local theme registry links on loopback unless an existing service is configured.
- Added eight design families, 31 React kits, portable DESIGN.md context and scoped component retrieval.
- Curated 784 resource packages with exact file bytes, shared asset storage, provenance and retained licenses.
- Added local UI/UX guidance, source and copy review, rendered-spacing checks and first-visit report review.
- Added validated theme configuration, owner-scoped rules, atomic local storage and conditional private Blob writes.
- Added bounded public URL extraction, DTCG exports and local browser/install/token comparison commands.
- Made command/file tools explicit: get-icon-files and get-video-render-commands. Removed unsupported dashboard finalization.
- Removed compatibility aliases, redundant resource wrappers and unused database dependencies.
- Strengthened package diagnostics and consistent protocol errors, including malformed assets and unavailable guidance.
- Updated website setup, resource browsing, isolated specimens, theme controls and tool documentation.

This release is a local candidate. Deployment, npm publication and Registry publication are separate release actions.
